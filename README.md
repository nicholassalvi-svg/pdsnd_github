### Project Title
Bike Share Data

### Description
The Bike Share Data progaram allows one to analyze bike share data from standard data sets, provided by Motivate and Udacity. The program has an interactive prompt that guides users through the process of analyzing the data for select data files. A user can select to read in a *.csv file for Chicago, New York City or Washington, and then will be prompted if they would like to filter by month, day, both, or not at all. Then the user will be able to view summary bike share statistics for the data they loaded and/or display some of the raw data depending on their selections.
